# ダンテの『天国篇』について

『神曲』の宇宙誌は、通常考えられているよりもはるかに単純で理解しやすいが、その詳細に立ち入ることは本書の範囲外である。その地理的側面については、第27歌の注で十分に触れており、その天文学の一般原則は、『饗宴』第2巻の第3章と第4章で、ダンテ自身が比類ない明晰さをもって展開している。体系全体についての優れた一般向け解説は、ヴィッテの『ダンテ論集』[^410-1]（論考 iv.『ダンテの宇宙誌』）に見いだされる。また、どの天文学書または百科事典にある*プトレマイオス体系*の説明も、その概略を十分に示してくれる。

現代の天文学の概念から、『神曲』に見られる概念へ移るための一般原則は、次のようにして導き出せる。われわれは今も、天体が昇り沈み、東から西へ回転すると言うが、そう記述される現象は実際には、地球がその軸のまわりを西から東へ日々回転することで生じると信じている。もし私たちが、信じていることではなく見ていることを描写する同じ原則を徹底すれば、地球が行うと信じている他のすべての運動を、同じ効果を生み出すであろう天体の運動の描写に置き換えることになる。そのとき、実際に見える現象に直接対応する、ギリシアおよび中世の天文学の言葉を話すことになる。したがって、地球が太陽のまわりを西から東へ回る年周運動の代わりに、太陽が地球のまわりを回る年周運動を置く。惑星が系の中心のまわりを西から東へ回ることは、現代のわれわれと同じように言い続ける。しかし、惑星が絶えず位置を変えている一方で、*われわれ*も中心のまわりを回って絶えず視点を変えているために生じる、惑星の運動における見かけ上の複雑さについては、*彼ら*が中心のまわりの主たる運動に、円周上を前後する二次的運動を付け加えていると仮定して説明する。この二次的運動は、西から東への進行を、あるときは遅らせ、あるときは速める。古代および中世の天文学者が行ったのは、まさにこのことであった。したがって彼らは、それぞれの惑星が（天の毎日の運動に加わるほかに）2つの運動をもつと考えた。1つは、地球を中心として回転する、より大きな天球、すなわち周円上の運動であり、もう一つは、より大きな天球の赤道上の一点を中心として回転する、より小さな天球、すなわち周転円上の運動である。外惑星である火星、木星、土星の場合、周円はその惑星自身が太陽のまわりを動く運動に対応し、周転円は地球の運動に対応する。内惑星である水星と金星の場合は、これを逆にしなければならない。最後に、地球の軸の向きが恒星に対して変わる、独楽のようなゆっくりとした運動は、「分点の歳差」として知られる現象を引き起こすが、これは天の毎日の回転の極に対するすべての恒星のゆっくりとした運動として記述される。こうして、古代と現代の天文学の根本的な幾何学問題は同一であり、見かけ上複雑で不規則な運動を単純で規則的な運動の組み合わせに分解することから成ると分かる。したがって、古代の天文学者が見いだした解は、その及ぶ範囲で今日も完全に有効であり、現代天文学に取り入れられている。

[^410-1]: 『ダンテ論集』カール・ヴィッテ博士著、ほか。ダックワース社、1898年。

ダンテに現れた宇宙を明確に思い描くことは、彼に想像力を通じて十分に共感し、彼の概念のなかで霊的世界と物質世界がどのような関係にあったか、また自然現象が彼の心のなかでどのような連想と結びついていたかを理解できる視点に達し、さらに彼の観察の科学的価値を認めるためにも重要である。

『天国篇』を直接理解するには、まず、ダンテが昇ってゆく諸天体の順序と、それらが伴う道徳的・霊的な連想を明確に思い描くことだけでほぼ足りる。

読者が現代の太陽系の図を1つ取り、太陽と地球の位置を単純に入れ替え（地球とその衛星である月を図の中心に置き、地球が記されている位置に太陽を置く）、地球から上へ進むダンテがたどり着く順序、すなわち1 月、2 水星、3 金星、4 太陽、5 火星、6 木星、7 土星、8 双子座、9 星々の彼方の目に見えない天蓋、10 光と愛の本質天を見ればよい。

付属の表は、詩全体の概略を示す。ダンテの数の構想はつねに、*三*を*七*つに細分し、残りとは性質の異なるものを加えて*九*にまで高め、さらにまったく別の次元で最後の1つを加えて*十*にすることに基づいている。

太陽下の諸天でダンテが出会うのは、地上的な弱さや汚れによって、かつての霊的可能性をある程度失った魂たちである。その喜びの質は完全に純粋で混じりけがないものの、彼らが完全に誠実であったなら得られたであろうものより、その喜びの強さは弱い。おそらく、この3つの天には、とりわけ揺るぎない*信仰*の欠如、天上の*希望*を部分的に地上的な希望に置き換えたこと、そして天上の*愛*を地上的な愛に置き換えたことを見いだせるのだろう。地球が空間に投じる円錐形の影は、金星天まで届くと信じられていた。このことの象徴的な意味を、これ以上力説する必要はない。

太陽という大いなる*光源*は、道徳的徳、すなわち枢要徳の指導者である*賢慮*（*Purg.* xxix. 130-132 を参照）と結びついており、賢慮はここでは最も広い意味に取られている。そして他の枢要徳がこれに続く。これは、魂の霊的な享受の調子と色合いが、それを獲得するために闘われた道徳的闘争の作用を受けていることを示している。

全篇に散りばめられた微妙な類推や示唆は、それぞれの惑星がそれぞれの魂の群れの顕現の場となることの、占星術上の適切さを示している。

双子座ではすべての魂が集まり、詩人の前に再び姿を現すが、彼が語り合うのは、使徒たちとわれらの始祖が属する最高の一群の成員だけである。

同じように、天使たちは第9天、すなわち *Primum Mobile*（原動天）に姿を現す。

しかし、これら9つの天のいずれも、霊の真の住処ではない。これらは、ダンテと霊たちの各群のために定められた、象徴的にふさわしい集合場所にすぎない。神と、祝福されたすべての霊、すなわち人間も天使も、空間のすべてが*ここ*であり、時間のすべてが*今*である至高天に住んでいる。詩人の幻視はついにそこへ到達し、そこで終わる。
