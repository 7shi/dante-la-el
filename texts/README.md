# Texts

The page-by-page transcriptions in [`ocr/`](../ocr/) reorganized into one Markdown file per section of each book: `texts/{dir}/{03d}-{title}.md`, where `{dir}` is the `ocr/` directory name. The files follow the printed book: its sections in book order, its headings, and its page boundaries, marked as `<!-- p. N (NNN) -->` with the printed page number and the scan number, so that any passage can be checked against `ocr/{dir}/NNN.png`.

The files are generated by a conversion script per book and are not edited by hand; corrections go into `ocr/`. The conventions and the per-book decisions are in [PLAN.md](PLAN.md).

| Directory | Book | Status |
|---|---|---|
| [en/](en/) | Carlyle, *The Inferno*, literal prose translation with the Italian text, 5th ed. (1889) | Done ([`convert_en.py`](convert_en.py)) |
| `en-oelsner/` | The same translation revised by H. Oelsner, Temple Classics (1903) | Planned |
| `la/` | Giovanni da Serravalle, Latin translation and commentary of the whole *Comedy* (1891) | Planned |
| `grc/` | Constantine Musurus, Greek verse translation of the *Inferno* (1882) | Planned |

The scripts run with [uv](https://docs.astral.sh/uv/) from the repository root, e.g. `uv run texts/convert_en.py`.
