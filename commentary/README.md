# commentary

Modern Greek commentary on each canto of the Divine Comedy, generated by an LLM from the Italian text of [dante-corpus](https://github.com/7shi/dante-corpus), together with a line-by-line Modern Greek translation of the whole canto.

> [!NOTE]
> The commentary and translations are machine-generated and have not been reviewed by translators or scholars.

All output is generated with `gpt-6-astra` in Modern Greek (`el`); the model and the target language are set once, in the [Makefile](Makefile).

The scripts were copied from [dante-commentary](https://github.com/7shi/dante-commentary) (as of commit `cf5a3ab`), which generates the same kind of commentary in Japanese, and adapted here; this directory does not depend on or refer to that repository at run time.

## Output

For each canto, `el/<canticle>/<NN>.*`:

- `<NN>.md` — commentary: headings per scene or theme, each quoting the key lines as `> N original` followed by `> (translation)`, then discussing their allegory and background; it ends with a `## Επίλογος — ...` section
- `<NN>.txt` — translation: one line of Modern Greek per line of the Italian text (blank where still untranslated)

## Usage

```bash
make generate CANTICLE=inferno CANTO=1-3
```

`CANTO` takes the SPEC syntax of dante-corpus (`N`, `N-M`, `N-`, `-M`, comma-separated); without it, every canto of the canticle is processed.

## scripts/generate.py

```bash
uv run scripts/generate.py <canticle> -m MODEL -l CODE -L NAME -d DIR [-c SPEC] [-r ROUNDS] [--no-think] [--save-usage]
```

argument | description | default
---|---|---
`canticle` | `inferno`, `purgatorio`, or `paradiso` | required
`-m`, `--model` | model name with an optional vendor prefix | required
`-l`, `--lang-code` | language code of the target language; selects its entry in `LANGUAGES` | required
`-L`, `--lang-name` | name of the target language, written into the prompts (e.g. `Modern Greek`) | required
`-d`, `--dir` | output directory | required
`-c`, `--canto` | cantos to process (SPEC syntax) | all
`-r`, `--rounds` | max passes to fill untranslated lines | `5`
`--no-think` | disable thinking output | enabled
`--save-usage` | record usage for any model (by default only `openai:` and `gpt-` models are recorded) | -

Each canto is processed in two steps:

1. **Commentary**: the Italian text, numbered line by line, is sent with the commentary prompt. If `<NN>.md` already exists, this step is skipped.
2. **Translation**: the `> N original` / `> (translation)` pairs quoted in the commentary seed the translation; a pair whose quoted original does not match the corpus line exactly is dropped. The original and the translations so far are then sent on alternating lines, with a placeholder on each untranslated line, and the model fills in those lines only. A filled line is rejected if it still holds the placeholder, copies the Italian, or has no letter of the target language in it; rejected lines are retried in the next round, up to `--rounds` rounds.

`<NN>.txt` is saved after every round. If it already exists, it is read back and only the missing lines are filled, so an interrupted run resumes where it stopped.

Both prompts are written in English, with the language name filled in. Each language code has an entry in `LANGUAGES` in the script:

- `letters`: a regular expression for the letters of the language, used to reject copied Italian
- `closing`: the word that opens the heading of the closing section (`Επίλογος` for `el`)
- `note`: an extra instruction added to both prompts (for `el`, to use the monotonic orthography)
