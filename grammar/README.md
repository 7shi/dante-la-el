# grammar

Grammar commentaries in English on the texts of the Divine Comedy, generated by an LLM.

> [!NOTE]
> The commentaries are machine-generated and have not been reviewed by translators or scholars.

`<code>-<source>/<canticle>/<NN>.md` holds a grammar commentary in English on every line of a source text, quoting the translation of `<code>` from [`commentary/`](../commentary/) (see [scripts/grammar.py](#scriptsgrammarpy)). The source is `it` (the Italian of dante-corpus, with the translations of `../commentary/<code>/`) or `grc` (Musurus's Greek, with the translations of `../commentary/<code>-grc/`). `carlyle/inferno/<NN>.md` explains the Italian printed in Carlyle's Inferno ([`texts/en/`](../texts/en/), whose lines are those of dante-corpus, with the readings and the spelling of that edition) against Carlyle's own English prose translation, printed with it.

The scripts and the Makefile are run from this directory. `scripts/grammar.py` uses the scripts of [`commentary/scripts/`](../commentary/scripts/) (`source.py`, `generate.py`, `fix_quote_blocks.py`).

## scripts/grammar.py

```bash
uv run scripts/grammar.py <canticle> -m MODEL -l CODE -d DIR -o OUT [-c SPEC] [-s SOURCE] [--size N] [-t TRIES] [--no-think] [--save-usage]
uv run scripts/grammar.py <canticle> -n -o OUT [-c SPEC] [-s SOURCE]
```

argument | description | default
---|---|---
`canticle` | `inferno`, `purgatorio`, or `paradiso` | required
`-m`, `--model` | model name with an optional vendor prefix | required unless `-n`
`-l`, `--lang-code` | language code of the translation | required unless `-n` or `-s carlyle`
`-d`, `--dir` | directory holding the translations `<canticle>/<NN>.txt` | required unless `-n` or `-s carlyle`
`-o`, `--out` | output directory for `<canticle>/<NN>.md` | required
`-c`, `--canto` | cantos to process (SPEC syntax) | all
`-s`, `--source` | source text to explain: `it`, `grc`, or `carlyle` | `it`
`--size` | lines per section, roughly | `30`
`-t`, `--tries` | answers asked for one section before giving up | `3`
`-n`, `--notes` | only list the translation notes of the saved commentaries | -
`--no-think` | disable thinking output | enabled
`--save-usage` | record usage for any model | -

From the Makefile of this directory (the output goes to `<code>-<source>/`, or `carlyle/`):

```bash
make grammar CANTICLE=inferno CANTO=1 SOURCE=carlyle
make grammar CANTICLE=inferno CANTO=1 LANG=en
make grammar-notes CANTICLE=inferno SOURCE=grc
make fix-grammar-quotes SOURCE=grc
```

The commentary explains the grammar and usage of every line of the source, in English: the forms of the words, the syntax, the particles, the usage of the language (Old Italian forms, or the Attic and poetic forms of Musurus's Greek), and how the translation renders the constructions. The content (story, allegory, background) and the meter are left out.

Each canto is cut into sections of about `--size` lines that end where a sentence of the source ends (`.`, `!`, `?`, and the Greek `;`, before any closing quote marks), or a clause (`;`, `:`, `·`) if no sentence ends between half and one and a half times `--size` lines on; the last section takes the rest of the canto when it is at most one and a half times `--size` lines. Each section is one call: the whole canto, every line followed by its translation in parentheses, then the prompt for the section's lines. The model writes one heading `## Lines a–b — <short title>`, then quotes the lines in order, one sentence or clause (one to four lines) at a time, as `> N original` / `> (translation)`, each followed by its explanation.

An answer is kept only if its heading names the section's lines, it quotes every line of the section exactly once and in order, and every quoted original and translation matches the source and the `.txt` (as `generate.py` matches quotes: up to the style of the quote marks and three other characters). The model must not rewrite the translation, so a quoted translation that does not match rejects the answer. A rejected answer is asked again, up to `--tries` times; if none passes, the canto is left unfinished and the run goes on with the next one (the exit status is then 1). The quote blocks of a kept answer are rebuilt from the source and the `.txt` (as `fix_quote_blocks.py` does) and the section is appended to `<NN>.md`, under the heading `# <Canticle> <N>`, so an interrupted run resumes after the last section saved. After the last section, a closing section `## Summary — <short title>` is asked for, with the canto and the commentary so far; a canto with a summary is complete and skipped.

With `-s carlyle`, the commentary compares the Italian with Carlyle's English instead. His translation is prose, printed page by page above the verse it renders, so the canto is sent page by page (`../commentary/scripts/source.py` reads the pages of `texts/en/`: the verse lines, then the English prose of the page, without the argument, the notes, and the footnote references). The quotes give the originals alone (`> N original`, consecutive lines in one block, no translation line), and the model quotes Carlyle's words in its explanation in double quotation marks `“…”`; an answer is also rejected if one of these quotations (of two words or more, each piece of one cut with an ellipsis) is not found in Carlyle's English of the canto, up to punctuation and case.

Where the model finds that the translation gets the grammar of a line wrong, it writes a paragraph opening with `Translation note:` instead of changing the translation. `--notes` lists these paragraphs with the lines quoted before them; after the `.txt` is corrected, `make fix-grammar-quotes` copies the corrected lines into the quote blocks.
