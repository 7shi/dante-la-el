⁴⁰ Cogita ammodo qui fuit ille qui dignus
    Collega fuit ad manutenendam barcham

Modo vult dicere Sanctus Thomas, quod adhuc sunt aliqui
boni Fratres in Ordine Sancti Dominici, sed illi sunt pauci,
id est, paucus pannus sufficeret ad ipsos vestiendum.
Bene sunt aliqui, scilicet oves, sive aliqui Fratres, qui ti-
ment dampnum, id est male operari, et stringunt se pastori,
id est, adherent Sancto Dominico et sue norme; sed sunt
ita pauci, quod cappas, scilicet ipsorum, fulcit paucus pan-
nus, id est paucus pannus fulciret cappas bonorum Fratrum,
quia sunt pauci boni.

Modo concludit Sanctus Thomas, dicens: Or, si verba mea
non fuerunt fioca, id est rauca, vel obscura, et si tua au-
dientia fuit actenta, si quidquid dixi ad mentem revocas,
id est bene retines, in parte erit tua voluntas contenta,
id est de uno dubio, quia de duobus querebas. Iam de uno
habes declaratum et tibi visibilis plantam, unde scinditur,
id est decerpitur, vel deciditur; videbis correctionem (quia
dubitas et restringit) que argumentat, scilicet illud dubium.
Ubi bene impinguntur, si non vanegiatur, id est non in-
tenditur vanitati; quia in Ordine Sancti Dominici Fratres
non impinguntur pinguedine spirituali, id est gratia di-
vina. si Fratres non actendunt ad vanitates, ad dignitates,
ad beneficia, etc.

id est quod paupertas stetit vidua a morte Christi usque
